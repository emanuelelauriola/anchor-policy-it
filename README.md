# Informativa sulla Privacy - Anchor

Ultimo aggiornamento: 13 Ottobre 2026

La tua privacy è di fondamentale importanza per noi. Questa Informativa sulla Privacy descrive come Anchor ("noi", "nostro") raccoglie, utilizza e protegge le informazioni quando utilizzi la nostra applicazione mobile.

## 1. Raccolta e Utilizzo dei Dati
Anchor è progettata per funzionare interamente sul tuo dispositivo. Tutti i dati relativi ai punteggi delle gare di tiro con l'arco, alle impostazioni e alle preferenze dell'utente sono memorizzati **esclusivamente in locale sul tuo dispositivo**.

Non raccogliamo, memorizziamo o trasmettiamo alcun dato personale o di punteggio su server esterni o cloud.

## 2. Servizi di Terze Parti
L'applicazione utilizza librerie standard (come plugin per l'audio e preferenze di sistema) che operano in locale senza tracciare le attività degli utenti a fini pubblicitari o di profilazione.

## 3. Sicurezza
Poiché i tuoi dati rimangono sul tuo dispositivo, la loro sicurezza è protetta dai sistemi di sicurezza nativi del tuo telefono (codice di sblocco, Face ID / Touch ID).

## 4. Contatti
Per qualsiasi domanda o chiarimento in merito a questa informativa, puoi contattarci tramite i canali di supporto dell'app.
